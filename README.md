# My Thoughts App

간단한 의견 수집 앱을 만들어줘. 이름과 의견을 입력하는 폼이 있으면 돼. 
이 앱에 데이터베이스를 연결해줘. 이름과 의견, 시간을 저장하는 테이블을 만들어서, 입력한 데이터가 새로고침해도 유지되게 해줘.
